# Instruções para a IA (Codex / Claude Code)

Este repositório é a central de edição de vídeos com IA da HN Gestão Comercial e Marketing.

Antes de editar qualquer vídeo:
1. Leia o `00-briefing.md` da pasta do vídeo.
2. Siga os critérios das skills em `.claude/skills/`: estilo, ritmo, legendas, movimento e composição.
3. Use as ferramentas de `ferramentas/` para cortar pausas e legendar.
4. Gere sempre uma amostra curta em `05-amostras/` antes do vídeo inteiro.
5. Nunca altere arquivos de `01-bruto/`.
6. Em correções, mexa só no trecho pedido.
